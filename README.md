# VRC Rowing Portal

The Vancouver Rowing Club's member portal: book sessions and boats, see the fleet, report damage,
and manage member profiles. Runs on Firebase (Hosting, Authentication, Firestore, Storage).

- **Live site:** https://vrc-rower-s-portal.web.app
- **First-time setup:** [docs/SETUP.md](docs/SETUP.md)
- **How it's built / notes for developers:** [CLAUDE.md](CLAUDE.md)

## Making changes
Changes arrive as pull requests. Each one runs the security tests and gets a **preview link**
(posted as a comment) so you can try it before anyone else sees it. **Merge** to put it live;
GitHub deploys automatically. To undo a change, use **Revert** on the merged pull request.
